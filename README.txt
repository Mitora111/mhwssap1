# MH Wilds Bilingual v20

## GitHub Pagesへの配置
1. 新しいGitHubリポジトリを作成する（Public）。
2. このZIPを展開し、中の `index.html` と `manifest.webmanifest` をリポジトリ直下へアップロードする。
3. Settings → Pages → Deploy from a branch → `main` / `/(root)` を選んで保存する。
4. 公開URLをSafariで開き、共有 → ホーム画面に追加。

## アイコンについて
この版は、現在確認できている紋章画像を旧Pages URLから参照する設定。
新しいPagesでアイコンが表示されることを確認するまでは、旧リポジトリ `mhwssap` を削除しないこと。
移行後にPNG画像を新リポジトリへ同梱すれば、旧リポジトリへの依存もなくせる。
